# 行野自驾出行

全国自驾旅行微信小程序，仓库同时保留原生 HTML、CSS、JavaScript 移动端原型。

## 功能

- 全国出发地与目的地设置
- 推荐路线、沿途景点和当地美食
- 动态多日日程
- 当日目的地附近加油站、充电站入口
- 地点收藏、同行好友邀请和个人中心

## 微信小程序运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. 在 `project.config.json` 中将 `touristappid` 替换为自己的小程序 AppID。
4. 开发阶段可使用测试号；正式发布前需要在微信公众平台完成主体、隐私协议和位置权限配置。

小程序源码位于 `miniprogram/`，包含：

- 全国起点和目的地选择
- 推荐路线与动态多日日程
- 沿途景点和当地美食
- 当日地点附近加油站和充电站
- 地点收藏、微信好友分享和个人中心

正式接入高德数据时，需要在高德开放平台创建微信小程序应用，并在微信公众平台配置合法请求域名。Web 服务 Key 不应硬编码到小程序前端，建议通过云函数或自有后端转发。

## Web 原型运行

直接打开 `index.html`，或使用静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。Web 原型入口为 `index.html`，仅用于浏览器预览，正式微信发布使用 `miniprogram/` 工程。
